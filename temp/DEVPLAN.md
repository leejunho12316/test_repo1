# 개발 계획

명세: `keyboard.md` (11장 1차 개발 기본값 포함), 블록 데이터: `patterns.md`

## 구조

```
temp/
  build.bat            앱(KeyboardGuitar.exe)과 테스트(tests.exe) 빌드
  KeyboardGuitar.exe   빌드 결과 (patterns.md와 같은 폴더)
  src/Core/            UI 없는 로직 (테스트 대상)
    KeyCodes.cs        물리 키(스캔코드) 식별자, 키 이름
    Fretboard.cs       튜닝, 음 높이, 3현-2현 보정, 키 매칭(KeyMap)
    Patterns.cs        patterns.md 파서
    Judge.cs           판정 엔진 (전체 모드 / 블록 모드)
    InputRouter.cs     키 입력 분배 (활성화 토글, 차단 여부, 시작 신호, 키 캡처)
    Settings.cs        settings.ini 읽기/쓰기
  src/App/             WinForms UI
  tests/Tests.cs       Core 단위 테스트
```

## 단계

### 1단계: 기본 동작
- 트레이 아이콘 (설정 열기 / 연습 시작·중지 / 종료, 활성 상태별 아이콘 색)
- 전역 키보드 훅: `Ctrl+Enter` 토글, 활성 중 모든 키 차단 (Win, Alt, Alt+Tab 예외), 자동 반복 무시, 스캔코드 기준
- 방향키 = 입력 초기화
- 화면 오른쪽 아래 O/X 오버레이
- patterns.md 읽기 (exe 폴더 → 실패 시 내장본)
- 전체 모드 판정: 시작 음 → 루트 역산, 상행/하행/혼합, 간격(건너뛰기/짝 패턴), 틀리면 초기화 전까지 X
- 설정 저장/불러오기 (UI 없이 기본값)
- 단위 테스트

### 2단계: 설정 페이지
- 상단: 투명도 바(10~100%, 설정창·O/X 둘 다), 환경설정 버튼
- 스케일 드롭다운(patterns.md 제목), 블록 모드 체크박스, 시작 음(1~N), 방향, 간격(2 미만 → 2, 3 이상일 때 짝 패턴 체크박스 활성)
- 변경 즉시 반영 + 입력 초기화 + 저장
- 닫기 = 트레이로 숨기기

### 3단계: 블록 모드
- 블록 모양을 프렛·줄 위치와 상관없이 판정, 블록 여러 개 중 아무거나 인정
- 3현-2현 보정 (모양 좌표 → 실제 프렛: 2현이면 +1)
- 블록 끝음(옥타브)에서 다음 블록으로 이어치기, 하행·혼합 지원
- 단위 테스트 (사용자 예시 문자열)

### 4단계: 미리보기와 키 매칭 창
- 미리보기: 켜기/끄기, 지판 그림, 키 이름 없음, 루트만 빨간색. 블록 모드면 블록들, 아니면 전체 음
- 키 매칭 창: 지판 그리드에 키 이름, 클릭으로 칸 선택 → 키 입력으로 할당, 중복 키는 기존 칸 비움, 단일 키만, 방향키 무시, 우클릭으로 비우기, 기본값 복원, 즉시 반영
