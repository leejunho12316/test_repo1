## 프로그램별 작성 내용 (초안)

### 1. AI-TD4-001 품질검사 데이터 조회
- 프로그램 설명: 각 라인의 비전 카메라에서 촬영된 이미지 원천 데이터를 조회한다.
- 사용 DB: AI_INSPECTION
- 조회 조건: PICTURE_TIME, LINE_NUMBER, DEFECT_YN
- 정렬 조건: PICTURE_TIME DESC, DEFECT_YN DESC, LINE_NUMBER ASC (2·3순위는 사용자 예시 기준, 화면설계서에는 촬영일시만 있음)
- 기능 설명
  1. 조회 일자의 시작일과 종료일, 라인 번호, 불량 여부를 입력한다. 기본 조회 기간은 오늘을 포함한 최근 7일이며, 라인 번호와 불량 여부의 기본값은 전체이다.
  2. AI_INSPECTION 테이블에서 조회 기간과 라인 번호, 불량 여부에 맞춰 촬영일시 최신순, 불량 여부, 라인 번호순으로 품질검사 원천 데이터를 조회한다.
  3. 이미지(IMAGE_PATH), 촬영 일자, 촬영 라인, 불량 여부를 페이지당 21건씩 표시하며, 정상은 초록색, 불량은 빨간색 테두리로 표시한다. 이미지를 누르면 확대해 보여준다.
- 관련 테이블: AI_INSPECTION

### 2. AI-TD4-002 품질검사 전처리 데이터 조회
- 프로그램 설명: 비전 카메라 이미지를 기반으로 한 AI 학습용 전처리 데이터를 조회한다.
- 사용 DB: AI_INSPECTION_PP, AI_INSPECTION (INSPECTION_ID로 연결)
- 조회 조건: AI_INSPECTION.PICTURE_TIME, AI_INSPECTION.LINE_NUMBER, AI_INSPECTION_PP.DEFECT_YN, AI_INSPECTION_PP.DEFECT_TYPE
- 정렬 조건: AI_INSPECTION.PICTURE_TIME DESC
- 기능 설명
  1. 조회 일자의 시작일과 종료일, 라인 번호, 불량 여부, 불량 유형을 입력한다. 기본 조회 기간은 오늘을 포함한 최근 7일이며, 나머지 조건 기본값은 전체이다.
  2. AI_INSPECTION_PP 테이블과 AI_INSPECTION 테이블을 원천 데이터ID로 연결해 조건에 맞는 전처리 데이터를 촬영일시 최신순으로 조회한다.
  3. id, 전처리 이미지(IMAGE_PP_PATH), 촬영일시, 불량 여부, 불량 유형, YOLO_TXT를 페이지당 6건씩 표시한다. 불량 여부는 불량이면 True, 정상이면 False로 표시하고, 정상이면 불량 유형과 YOLO_TXT는 '-'로 표시한다. 전처리 이미지를 누르면 확대해 보여준다.
- 관련 테이블: AI_INSPECTION_PP, AI_INSPECTION

### 3. AI-TD4-005 품질검사 AI 모델링
- 프로그램 설명: 전처리 데이터와 품질검사 AI 모델 학습 정보를 함께 조회한다.
- 사용 DB: AI_INSPECTION_PP, AI_INSPECTION_MODEL_TRAIN
- 조회 조건: (전처리) PP_TIME 기준 최신 완료월 한 달 / (학습 정보) TRAIN_DATETIME
- 정렬 조건: (전처리) PP_TIME DESC (화면설계서에 없음, 확인 필요) / (학습 정보) TRAIN_DATETIME DESC
- 기능 설명
  1. 학습 정보의 조회 시작일과 종료일을 입력한다. 기본 조회 기간은 전월 동일일부터 오늘까지이며, 전월에 동일 일자가 없으면 전월 말일을 시작일로 한다.
  2. AI_INSPECTION_PP 테이블에서 조회 조건과 관계없이 최신 완료월 한 달의 전처리 데이터를 조회해 전처리 이미지, 불량 여부, 불량 유형을 페이지당 8건씩 표시한다.
  3. AI_INSPECTION_MODEL_TRAIN 테이블에서 조회 기간에 맞춰 학습일시 최신순으로 모델명, 학습일시, 학습시간, 알고리즘, mAP50(MAP_SCORE), 비고를 페이지당 8건씩 조회한다.
- 관련 테이블: AI_INSPECTION_PP, AI_INSPECTION_MODEL_TRAIN

### 4. AI-TD4-006 품질검사 AI 모델 검증
- 프로그램 설명: 품질검사 AI 모델별 학습 정보와 검증 결과를 조회한다.
- 사용 DB: AI_INSPECTION_MODEL_TRAIN
- 조회 조건: TRAIN_DATETIME
- 정렬 조건: TRAIN_DATETIME DESC
- 기능 설명
  1. 학습 정보의 조회 시작일과 종료일을 입력한다. 기본 조회 기간은 전월 동일일부터 오늘까지이며, 전월에 동일 일자가 없으면 전월 말일을 시작일로 한다.
  2. AI_INSPECTION_MODEL_TRAIN 테이블에서 조회 기간에 맞춰 학습일시 최신순으로 모델명, 학습일시, 학습시간, 산출 정확도(ACCURACY), 손실 값(LOSS), 검증 손실값(VAL_LOSS), 비고를 페이지당 12건씩 조회한다.
  3. 정확도는 %로 표시하고, 손실 값과 검증 손실값은 % 없이 소수 4자리로 표시한다. NULL은 '-', 실제 0은 '0.0000'으로 구분한다.
  4. 비고(REMARK)에는 손실함수명, 스케일링, 검증기간, 저장 에포크를 기록한다.
- 관련 테이블: AI_INSPECTION_MODEL_TRAIN

### 5. AI-TD4-009 대시보드
- 프로그램 설명: 완제품 불량률과 시간당 생산량의 월별 추이를 표시한다.
- 사용 DB: DASHBOARD_MONTHLY_DEFECT_RATE, DASHBOARD_PROD_MONTHLY
- 조회 조건: STAT_MONTH (현재 월을 제외한 직전 12개월)
- 정렬 조건: STAT_MONTH ASC
- 기능 설명
  1. 조회 기간은 현재 월을 제외한 직전 12개월로 설정한다.
  2. DASHBOARD_MONTHLY_DEFECT_RATE 테이블에서 조회 기간의 전체 검사 수(총생산량), 불량 수, 불량율을 월별로 집계해, 전체 검사 수와 불량 수는 첫 번째 축의 겹친 막대로, 불량율은 두 번째 축의 선으로 혼합 그래프를 출력한다.
  3. DASHBOARD_PROD_MONTHLY 테이블에서 조회 기간의 시간당 평균 생산량을 월별로 집계해 선 그래프로 출력한다.
  4. 두 그래프를 15초 간격으로 번갈아 출력한다.
- 관련 테이블: DASHBOARD_MONTHLY_DEFECT_RATE, DASHBOARD_PROD_MONTHLY

### 6. AI-TD4-010 AI 기반 품질검사 합불 판정
- 프로그램 설명: 촬영 이미지를 품질검사 AI로 판정한 결과를 모니터링한다.
- 사용 DB: AI_INSPECTION_RES, AI_INSPECTION_PP, AI_INSPECTION
- 조회 조건: AI_INSPECTION.PICTURE_TIME, AI_INSPECTION.LINE_NUMBER, AI_INSPECTION_RES.DEFECT_YN, AI_INSPECTION_RES.DEFECT_TYPE
- 정렬 조건: AI_INSPECTION.LINE_NUMBER ASC, AI_INSPECTION.PICTURE_TIME DESC
- 기능 설명
  1. 조회 일자, 라인 번호, 불량 여부, 불량 유형을 선택한다. 조회 일자 기본값은 오늘, 나머지는 전체이다.
  2. AI_INSPECTION_RES 테이블을 전처리ID로 AI_INSPECTION_PP와, 원천 데이터ID로 AI_INSPECTION과 연결해 조건에 맞는 판정 결과를 조회한다.
  3. 이미지 목록을 페이지당 7건씩 표시하며 정상은 초록색, 불량은 빨간색 테두리로 표시한다.
  4. 이미지를 선택하면 선택 표시와 함께 촬영일시, 라인 번호, 합격/불합격, 불량 유형과 선택한 이미지를 표시한다.
- 관련 테이블: AI_INSPECTION_RES, AI_INSPECTION_PP, AI_INSPECTION

### 7. AI-TD4-011 AI 기반 품질검사 내역조회
- 프로그램 설명: 품질검사 AI 판정 내역을 라인 번호, 불량 여부, 불량 유형별로 조회한다.
- 사용 DB: AI_INSPECTION_RES, AI_INSPECTION_PP, AI_INSPECTION
- 조회 조건: AI_INSPECTION_RES.PRED_DATETIME, AI_INSPECTION.LINE_NUMBER, AI_INSPECTION_RES.DEFECT_YN, AI_INSPECTION_RES.DEFECT_TYPE
- 정렬 조건: AI_INSPECTION_RES.PRED_DATETIME DESC, AI_INSPECTION.LINE_NUMBER ASC
- 기능 설명
  1. 조회 기간의 시작일과 종료일, 라인 번호, 불량 여부, 불량 유형을 선택한다. 라인 번호, 불량 여부, 불량 유형의 기본값은 전체이다.
  2. AI_INSPECTION_RES 테이블에서 조건에 맞는 판정 내역을 판별일시 최신순, 라인 번호순으로 조회한다. 라인 번호는 전처리ID와 원천 데이터ID로 연결해 가져온다.
  3. 예측 일시, 라인 번호, 불량 여부(정상/불량), 불량 유형을 페이지당 12건씩 표시한다.
- 관련 테이블: AI_INSPECTION_RES, AI_INSPECTION_PP, AI_INSPECTION
