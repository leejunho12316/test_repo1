□ 업무 설명
- 각 라인의 비전 카메라에서 촬영된 이미지 데이터를 조회한다.
□ 화면 설명
- ❶ 조회 조건: 조회 일자의 시작일·종료일, 라인 번호, 불량 여부를 입력한다.
- ❷ 목록: 이미지, 촬영 일자, 촬영 라인, 불량 여부를 표시한다.
- 이미지 클릭 시 확대 조회가 가능하다.
- 촬영된 김발장 이미지의 불량 여부는 테두리 색으로 표시한다.
초록색 테두리 : 정상
빨간색 테두리 : 불량
- 불량 여부 선택을 통해 정상, 불량, 전체 조회를 변경한다.
□ 기능 설명
- ❶ 조회 일자·라인 번호·불량 여부을 설정한 뒤 조회 아이콘을 누르면 조건에 맞는 ❷ 목록을 표시한다.
- ❷ 목록 하단의 페이지 번호를 누르면 해당 페이지를 21건씩 조회한다.
□ 조회 조건
- 촬영 날짜 및 시각으로 이미지를 조회하며, 최근 촬영 시각이 상단에 오도록 정렬한다.
- 최초 조회 기간은 오늘을 포함한 최근 7일이다.
- 조회 시작일은 오늘의 6일 전, 종료일은 오늘이다.
- 라인 번호와 불량 여부의 기본값은 각각 ‘전체’이며, ‘전체’인 코드 조건은 제한 없이 조회한다.
- 화면 예시 이미지는 제공된 샘플을 사용해 AI로 생성한 이미지이다.

- 불량 여부가 False라면 불량 유형, yolo_txt는 따로 라벨링하지 않는다.

﻿□ 업무 설명
  - 품질 검사 AI 모델의 학습 정보와 산출 정확도, 손실 값, 검증 손실값을 조회한다.
□ 화면 설명
  - ❶ 날짜 조건: AI 학습 정보를 조회할 시작일과 종료일을 입력한다.
  - ❷ 목록: 행 번호, 모델명, 학습일시, 학습시간을 표시한다.
  - 산출 정확도(%), 손실 값, 검증 손실값, 비고를 이어서 표시한다.
□ 기능 설명
  - ❶ 시작일과 종료일을 설정한 뒤 조회 아이콘을 누르면 ❷ 목록을 갱신한다.
  - ❷ 모델별 정확도와 손실 값을 함께 확인한다. 손실 값의 조건은 비고에서 확인한다.
  - ❷ 목록 하단의 페이지 번호를 누르면 해당 페이지를 12건씩 조회한다.
□ 조회 조건
  - 학습일시를 기준으로 날짜 범위를 조회한다.
  - 기본 조회 기간은 전월 동일일부터 오늘까지의 최근 1달이다.
  - 전월에 동일한 날짜가 없으면 전월 말일을 시작일로 적용한다.
□ 학습 지표 표시 기준
  - 기존 정확도(ACCURACY)의 퍼센트 표시를 유지한다. LOSS와 VAL_LOSS에는 %를 붙이지 않는다.
  - 손실 값과 검증 손실값은 저장된 모델에 대응하는 에포크의 손실 값이다.
  - 손실 값은 소수 4자리로 표시한다. NULL은 '-'(미산출), 실제 0은 '0.0000'으로 구분한다.
  - 학습과 검증에는 같은 손실함수를 사용하며, 값은 손실함수와 데이터 스케일에 따라 해석한다.
  - 비고(REMARK)에는 손실함수명, 스케일링, 검증기간, 저장 에포크를 기록한다.
  - 예시 손실 값은 학습 구간에서 산출한 범위로 목표값을 0~1 정규화한 MSE 기준이다.
  - 화면의 수량과 손실 값은 설명을 위한 예시이며, 실제 측정한 모델 성능을 뜻하지 않는다.
