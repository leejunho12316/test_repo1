# 화면설계서(SF-TD3) 수정 내용 정리

- 대상: `SF-TD3 화면설계서_대경_v1.0.pptx` (1029 피드백 반영본)
- 근거: `대경 산출물 피드백.md`, 화면 페이지 및 설명 페이지 수정 결과
- 공통 용어 통일: **수집 일시**(촬영 일시·조회 일자) / **학습 일시**(학습일자·학습일시) / **검사 일시**(판별 일시·예측 대상 일자) / 불량 여부 **정상·불량**(True·False) / 불량 유형은 **유형명**(class 번호 X)

## TD3-001 품질검사 데이터 조회 (화면 2·3, 설명 4)
- 조회 조건: 수집 일시, 라인 번호 (불량 여부 삭제)
- 목록: ID, 수집 일시, 라인 번호, 파일명, 비고 (**불량 여부 삭제** — 원천 데이터에는 판정 결과가 없음)
- 팝업: 테두리 색(정상/불량) 표시 삭제, 좌측 하단 문자열 "[공정라인]"만 표시

## TD3-002 품질검사 전처리 데이터 조회 (화면 5·6, 설명 7)
- 조회 조건: 수집 일시, 라인 번호, 불량 여부, 불량 유형
- 목록: ID, 수집 일시, 라인 번호, **파일명(추가)**, 불량 여부, 불량 유형, 비고 (**yolo_txt 화면 미표시**, DB에는 유지)
- 불량 여부 정상/불량 표시, 불량 유형은 유형명 표시, 한 이미지에 **여러 유형 동시 표시** 가능 (예: "살 끊김 불량, 엮음실 불량")
- ❺ 전처리 프로그램(labelImg)을 프로그램 내에서 실행해 직접 라벨링 → ❻ 업데이트로 목록 반영
- 전처리 데이터 컬럼은 labelImg 결과 형식에 따라 달라질 수 있음

## TD3-003 품질검사 AI 모델링 (화면 9, 설명 10)
- 조회 조건 라벨: 학습일자 → **학습 일시**
- 상단 전처리 목록: TD3-002와 같은 컬럼 (수집 일시, 파일명, yolo_txt 제외), 최근 한 달 조회, 5건씩
- 하단 학습 정보: 모델명, 학습 일시, 학습시간, 알고리즘, 비고 (**mAP50 미표시**), 8건씩

## TD3-004 품질 검사 AI 모델 검증 (화면 11, 설명 12)
- 목록: 모델명, 학습 일시, 학습시간, 손실 값, 검증 손실값, 정확도, **정밀도(추가)**, **재현율(추가)**, mAP50, 비고
- 손실 값 = train box·cls·dfl loss 합, 검증 손실값 = val box·cls·dfl loss 합 (저장 모델 best.pt 에포크 기준)
- 정확도(ACCURACY)는 사업계획서 AI 성능 목표 지표, % 표시 / 정밀도·재현율·mAP50 소수 3자리
- 비고: 저장 에포크 등 특이사항 기록 (MSE·정규화 관련 기준 삭제)

## TD3-005 대시보드 (화면 14·15, 설명 16)
- 월별 불량률: 막대(총생산량·불량 수량) 삭제, **불량률 선 그래프만** 표시, x축 월 단위
- 표시 기간: 직전 12개월 + **현재 월(실시간)** (예: 2025-10 ~ 2026-10)
- 월 평균 시간당 생산량: 동일 기간, 15초 간격 전환

## TD3-006 AI 기반 품질검사 합불 판정 (화면 17·18, 설명 19)
- 이력 목록·조회 조건·페이지 삭제 → **가장 최근 검사 1건**만 실시간 표시
- 왼쪽 검사 이미지(불량 위치 박스 + 유형명), 오른쪽 OK/NG
- 표시 항목: 수집 일시, 검사 일시, 라인 번호, 파일명, 불량 유형(여러 개면 모두, 정상이면 '-')
- 신뢰도·탐지 개수·추론 시간 미표시

## TD3-007 AI 기반 품질검사 내역조회 (화면 20, 설명 21)
- 조회 조건: 검사 일시, 라인 번호, 불량 여부, 불량 유형 (기본 최근 1달)
- 목록: 검사 일시, 라인 번호, 불량 여부, 불량 유형, **비고(추가)**
- 화면 좌측에 선택한 행의 검사 이미지 표시 (추가)
