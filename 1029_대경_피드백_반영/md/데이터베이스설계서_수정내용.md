# 데이터베이스설계서(SF-TD5) 수정 내용 정리

- 대상: `SF-TD5 데이터베이스설계서_대경_V1.0.hwp` (10/28판, 1029 피드백 반영)
- 근거: `대경 산출물 피드백.md`, `화면설계서_수정내용.md`(TD3-001~007 화면 수정 결과)
- 공통: 용어 통일(수집 일시·학습 일시·검사 일시·불량률)은 컬럼명과 컬럼ID 모두 반영, 판별 결과(RES)는 원천 데이터 참조로 변경

## AI_INSPECTION (품질검사 원천 데이터)
1. 추가/수정/삭제된 칼럼
   - 삭제: 불량 여부 DEFECT_YN TINYINT(1) (TD3-001)
   - 수정: 촬영 일시 PICTURE_TIME DATETIME → 수집 일시 COLLECT_TIME DATETIME (TD3-001)
2. 변경된 제약조건: 없음
3. 기타 고려사항: 원천 데이터에는 판정 결과가 없으므로 불량 여부 제거. 정렬·조회 기준 컬럼은 COLLECT_TIME, 파일명(FILE_NAME)은 기존 컬럼 사용

## AI_INSPECTION_PP (품질검사 전처리 데이터)
1. 추가/수정/삭제된 칼럼
   - 수정: 불량 유형 DEFECT_TYPE NVARCHAR(8) → NVARCHAR(100) (TD3-002)
2. 변경된 제약조건: 없음 (INSPECTION_ID FK → AI_INSPECTION 유지)
3. 기타 고려사항: 유형명(자연어) 저장 및 한 이미지에 여러 유형 동시 저장("살 끊김 불량, 엮음실 불량"). DEFECT_YN은 TINYINT 유지하고 화면에서 0/1 → 정상/불량 변환, YOLO_TXT는 DB 유지·화면 미표시. 수집 일시·라인 번호·파일명은 AI_INSPECTION 조인, 컬럼은 labelImg 결과 형식에 따라 변동 가능

## AI_INSPECTION_MODEL_TRAIN (품질검사 AI 모델 학습 정보)
1. 추가/수정/삭제된 칼럼
   - 추가: 정밀도 PRECISION_SCORE DOUBLE (TD3-004)
   - 추가: 재현율 RECALL_SCORE DOUBLE (TD3-004)
   - 추가: 학습 박스/분류/DFL 손실값 TRAIN_BOX_LOSS, TRAIN_CLS_LOSS, TRAIN_DFL_LOSS DOUBLE (손실 값 LOSS 다음)
   - 추가: 검증 박스/분류/DFL 손실값 VAL_BOX_LOSS, VAL_CLS_LOSS, VAL_DFL_LOSS DOUBLE (검증 손실값 VAL_LOSS 다음)
   - 수정: 학습일시 TRAIN_DATETIME → 학습 일시 TRAIN_DATETIME (컬럼명만, 타입 유지) (TD3-003·004)
2. 변경된 제약조건: 없음
3. 기타 고려사항: 신규 컬럼은 산출 정확도(ACCURACY) 다음에 배치(화면 컬럼 순서), PRECISION은 MariaDB 예약어라 _SCORE 접미사 사용(MAP_SCORE와 통일). LOSS/VAL_LOSS는 train/val의 box+cls+dfl loss 합이며 각 항목도 개별 컬럼으로 저장(모두 best.pt 에포크, results.csv 기준), ACCURACY는 사업계획서 성능 목표 지표(% 표시)

## AI_INSPECTION_RES (품질검사 판별 결과)
1. 추가/수정/삭제된 칼럼
   - 수정: 전처리 이미지 ID INSPECTION_PP_ID BIGINT(8) → 원천 데이터ID INSPECTION_ID BIGINT(8) (TD3-006·007)
   - 수정: 판별 일시 PRED_DATETIME → 검사 일시 INSPECT_DATETIME (타입 유지) (TD3-006·007)
   - 수정: 불량 유형 DEFECT_TYPE NVARCHAR(8) → NVARCHAR(100) (TD3-006·007)
2. 변경된 제약조건: FK 대상 AI_INSPECTION_PP → AI_INSPECTION (실시간 판정은 라벨링 전 원천 이미지 검사). TRAIN_MODEL_ID FK 유지
3. 기타 고려사항: CONFIDENCE·DETECT_CNT·INFERENCE_TIME은 화면 미표시지만 DB 유지. TD3-006은 최신 1건(INSPECT_DATETIME 내림차순), 수집 일시·파일명·라인 번호는 AI_INSPECTION 조인. RESULT_IMAGE_PATH로 박스 표시 이미지 제공, REMARK는 TD3-007 비고 컬럼

## DASHBOARD_MONTHLY_DEFECT_RATE (월별 불량률)
1. 추가/수정/삭제된 칼럼
   - 수정: 불량율 DEFECT_RATE → 불량률 DEFECT_RATE (컬럼명만, 타입 유지) (TD3-005)
2. 변경된 제약조건: 없음
3. 기타 고려사항: 테이블명 월별 불량율 → 월별 불량률. 화면은 불량률만 표시하나 TOTAL_CNT·DEFECT_CNT는 계산 근거로 유지, 현재 월은 조회 시점까지 실시간 집계로 갱신

## DASHBOARD_PROD_MONTHLY (월 평균 시간당 생산량)
1. 추가/수정/삭제된 칼럼: 없음
2. 변경된 제약조건: 없음
3. 기타 고려사항: 현재 월은 실시간 집계로 갱신, 기간은 불량률 대시보드와 동일(직전 12개월 + 현재 월) (TD3-005)
