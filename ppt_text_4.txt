□ 업무 설명
  - 실제 매입 가격과 견적 산출값을 품목과 상태·등급별로 비교한다.

□ 화면 설명
  - ❶ 품목과 상태·등급을 선택하여 조회한다.
  - ❷ 비교 목록은 품목과 상태·등급별로 구분하여 표시한다.
  - 평균 매입 가격과 매입 견적 산출값은 각각 1달전·2달전·3달전 열로 표시한다.
  - ❸ 선택한 품목과 상태·등급을 표시한다.
  - ❹ 선택한 행의 평균 매입 가격과 산출값을 월별 그래프로 비교한다.

□ 기능 설명
  - ❶ 조회 버튼을 누르면 선택한 조건에 맞는 목록을 표시한다.
  - ❷ 행을 선택하면 선택 표시와 ❸ 선택 정보, ❹ 비교 그래프를 함께 갱신한다.
  - ❷ 목록은 품목코드순으로 정렬하며, 같은 품목은 NEW, USED 순서와 A부터 D까지의 등급순으로 표시한다.
  - ❷ 목록 하단의 페이지 번호를 누르면 해당 페이지를 6건씩 조회한다.

□ 조회 조건
  - 품목과 상태·등급은 기본적으로 전체를 조회한다.
  - 현재월 2026-10의 1달전·2달전·3달전은 각각 2026-09·2026-08·2026-07이다.
